# Phase 4 — UI Foundation and Design System

Part of [[React Native Roadmap - Index|React Native Application — Complete Implementation Roadmap]]. Previous: [[Phase 3 - Navigation and Application Shell]]. Next: [[Phase 5 - API Client and Backend Contract]].

**Objective:** Build reusable UI primitives before implementing feature screens.

### Tasks

- Choose NativeWind or StyleSheet-based styling.
- Define color, spacing, typography, and radius tokens.
- Implement reusable buttons.
- Implement text inputs and labels.
- Implement screen containers.
- Implement loading indicators.
- Implement empty-state components.
- Implement error-state components.
- Implement confirmation dialogs.
- Implement accessible interactive components.
- Verify keyboard behavior on mobile.
- Verify responsive behavior on web.
- Add light/dark theme support if required.

### Design principles

- Keep shared components platform-neutral where practical.
- Use platform-specific components when interaction patterns differ.
- Do not force mobile layouts onto desktop screens.
- Support accessibility labels, focus behavior, and appropriate touch targets.
- Avoid unnecessary component abstraction.

### Exit criteria

- Common UI elements are reusable.
- Loading, empty, and error states have consistent presentation.
- Mobile and web layouts remain usable at supported screen sizes.

**Deliverable:** A reusable UI foundation.
