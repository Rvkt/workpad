# Immediate Next Actions

Part of [[React Native Roadmap - Index|React Native Application — Complete Implementation Roadmap]].

Start with these tasks in order:

1. Create the Expo TypeScript project.
2. Verify Android and web startup.
3. Establish TypeScript strict mode and import aliases.
4. Create the directory structure.
5. Configure Expo Router layouts.
6. Implement the initial UI primitives.
7. Build the Axios API client.
8. Configure TanStack Query.
9. Create the first small Zustand store.
10. Implement authentication only after the API and state foundations are in place.

**Engineering rule:** Complete one phase, verify its exit criteria, and then move forward. Avoid implementing authentication, feature modules, storage persistence, and complex caching simultaneously before the underlying architecture is established.

**Deferred for later:** Monitoring, CI/CD, automated deployment, and production release infrastructure.
