# Suggested Milestones and Definition of Done

Part of [[React Native Roadmap - Index|React Native Application — Complete Implementation Roadmap]].

## Milestones

| Milestone | Completion criteria |
|---|---|
| M1 — Foundation | Project runs on supported platforms |
| M2 — Navigation | Route structure and layouts work |
| M3 — API layer | Requests, timeouts, and errors are handled |
| M4 — State | Zustand and TanStack Query are configured |
| M5 — Authentication | Session lifecycle and protected routes work |
| M6 — Forms | Validation and backend errors are integrated |
| M7 — Features | Required product functionality is complete |
| M8 — Testing | Critical flows pass automated tests |
| M9 — Verification | Android, iOS, and web behavior is verified |
| M10 — Release preparation | Manual build and configuration instructions are complete |

The milestones are ordered by dependency. Schedule estimates should be added after defining the actual product scope.

## Definition of Done

A phase is complete only when its acceptance criteria pass.

- Code is typed and follows established conventions.
- Responsibilities are separated appropriately.
- Errors and failure states are handled.
- Relevant tests pass.
- Platform compatibility has been verified where applicable.
- No credentials or secrets are exposed.
- Documentation is updated when architecture or workflows change.
- No unnecessary dependencies or abstractions have been introduced.
