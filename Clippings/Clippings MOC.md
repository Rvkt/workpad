## Overview
Index of all notes in `Clippings/`. Auto-generated via Dataview — add a note to this folder and it appears below.

```dataview
TABLE WITHOUT ID
  file.link AS "Note",
  source AS "Source",
  published AS "Published"
FROM "Clippings"
WHERE file.name != "Clippings MOC" AND file.name != "Clippings Index"
SORT file.name ASC
```
